# Держусь: счётчик дней без

Android-приложение (Kotlin, Jetpack Compose, виджет на Glance).
Универсальный счётчик: сигареты, алкоголь, сладкое, соцсети или своя цель.

## Как открыть и запустить
1. Установите Android Studio Ladybug (2024.2.1) или новее.
2. File → Open → выберите эту папку. Дождитесь Gradle Sync (нужен интернет).
3. Если Studio пожалуется на отсутствие gradlew, ничего страшного: она сама скачает Gradle 8.9 по gradle-wrapper.properties.
4. Нажмите Run на телефоне (с включённой отладкой по USB) или в эмуляторе.
5. Виджет: долгое нажатие на рабочем столе → Виджеты → «Держусь».

## Что внутри
- Несколько целей одновременно, дата и время начала (можно задним числом)
- Кольцо прогресса до следующей цели, секундомер, экономия, рекорд, уровни
- Награды за дни и за сэкономленные деньги, конфетти при получении
- «Тянет»: дыхательное упражнение и фразы поддержки
- «Сорвался»: новая серия с сохранением рекорда или продолжение счёта
- Ежедневное уведомление в 9:00 с похвалой (WorkManager)
- Виджет на главный экран (первая цель из списка)
- Кнопка «Поделиться»

## Публикация в RuStore
Build → Generate Signed App Bundle / APK → создайте и сохраните ключ (keystore).
Без этого ключа вы не сможете выпускать обновления, так что сделайте его копию.

## Файлы
- `Model.kt` — модель, расчёты, хранение
- `Awards.kt` — награды
- `Praise.kt` — фразы поддержки
- `HomeScreen.kt`, `AddScreen.kt`, `CravingScreen.kt`, `AwardsScreen.kt` — экраны
- `DerzhusWidget.kt` — виджет
- `Notifications.kt` — уведомления и расписание
